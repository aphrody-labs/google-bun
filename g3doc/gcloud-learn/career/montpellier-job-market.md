# Marche Tech Montpellier — Cartographie & Opportunites de Recrutement

## 1. Vue d'Ensemble du Bassin Montpellierain

Montpellier constitue un pole technologique majeur du sud de la France, labellise French Tech. Le tissu economique se structure autour de 4 categories cles :

1. **Editeurs R&D / Pure Players Tech** : Entreprises a produit propre manipulant des volumes significatifs de donnees et du trafic web mondial.
2. **Cabinets de Conseil & ESN Specialisees** : Demande continue pour le placement en mission d'ingenierie logicielle, cloud et devops aupres de clients regionaux et nationaux.
3. **Startups / Scale-ups SaaS & IA** : Forte concentration incubee au BIC (Business & Innovation Centre) de Montpellier, axee sur les agents autonomes, la productivite B2B et la MedTech/AgriTech.
4. **Grands Comptes / Industrie / Energie** : Transition energetique, IoT, solaire, mobilite et ferroviaire.

## 4. Competences Cles Recherchées et Facteurs de Differenciation

1. **Rust & Systemes Bas Niveau** :
   - Manipulation FFI, zero-copy, async (Tokio), interfaçage WebAssembly ou micro-services a haute concurrence.
   - Atout rare sur le marche local, tres valorise chez les editeurs cybers et infra.
2. **TypeScript & Runtimes Modernes** :
   - Maitrise des runtimes performants (Bun, Node/Deno), TypeScript strict, API GraphQL/REST, architectures event-driven.
   - Front-end React / Next.js / TanStack associe a une comprehension backend approfondie.
3. **Python & AI Engineering** :
   - Python 3.12+, frameworks agents (LangGraph, CrewAI, AutoGen), RAG, embeddings vectoriels, fine-tuning et quantisation locale.
   - Industrialisation d'APIs LLM, streaming SSE, prompt caching.
4. **Cloud & DevOps (GCP, AWS)** :
   - Terraform / OpenTofu, Kubernetes (GKE, EKS), Docker, CI/CD automatisee.
   - Connaissance solide de GCP (BigQuery, Cloud Run, Vertex AI, IAM, Workload Identity Federation).
